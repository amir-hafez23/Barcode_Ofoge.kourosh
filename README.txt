# شمارشگر بارکد کالا

## اجرا
- برای تست ساده، `index.html` را در Chrome یا Edge باز کنید.
- برای نصب PWA و استفاده از دوربین، برنامه را روی یک هاست HTTPS یا localhost اجرا کنید.
- روی گوشی، آدرس وب‌اپ را در Chrome باز کنید و از منوی مرورگر گزینه Install app / Add to Home screen را بزنید.

## امکانات
- ورود دستی و پشتیبانی از بارکدخوان USB/HID (مانند صفحه‌کلید)
- اسکن دوربین در مرورگرهای سازگار با BarcodeDetector
- تعریف و ویرایش نام کالا برای هر بارکد
- افزایش/کاهش تعداد، صفرکردن شمارش، جست‌وجو
- ذخیره خودکار روی همان دستگاه با localStorage
- ورود XLSX/XLS/CSV و خروجی XLSX/CSV

## قالب اکسل
ردیف اول بهتر است عنوان داشته باشد: «بارکد» و «نام کالا». اگر عنوان‌ها تشخیص داده نشوند، ستون اول بارکد و ستون دوم نام کالا فرض می‌شود.

## محدودیت مهم
اطلاعات فعلاً بین گوشی و کامپیوتر همگام نمی‌شوند؛ هر دستگاه بانک اطلاعاتی محلی خودش را دارد. برای همگام‌سازی زنده و چندکاربره باید backend و پایگاه داده آنلاین اضافه شود.
قابلیت XLSX به بارگذاری کتابخانه SheetJS از CDN نیاز دارد؛ CSV بدون آن هم کار می‌کند. اسکن دوربین نیازمند HTTPS/localhost و مرورگر سازگار است.
